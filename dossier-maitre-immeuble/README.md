# Dossier maître de l'immeuble

Gabarit Excel pour la gestion Progim : un fichier par immeuble géré.

- `Dossier maitre immeuble - GABARIT.xlsx` : le gabarit à copier (mode d'emploi dans le premier onglet).
- `generer_gabarit.py` : régénère le gabarit (`python generer_gabarit.py [sortie.xlsx]`). Modifier ce script plutôt que le fichier pour faire évoluer le gabarit.

Onglets : Fiche (identification, propriétaire et mandat, équipe, accès, tableau de bord des échéances), Unités et baux
(avec dates d'avis de modification selon l'art. 1942 C.c.Q.), Assurances, Taxes, Contrats, Entretien et inspections,
Équipements, Travaux, Contacts, Documents, Paramètres (seuils d'alerte et listes déroulantes).
